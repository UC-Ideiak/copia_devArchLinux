# Rehabilitación de CP Bikunaenea

Proyecto de rehabilitación energética para la comunidad de propietarios Bikunaenea en Bizkaia.

## Mejoras realizadas

Se implementó un sistema de aislamiento térmico exterior que redujo significativamente el consumo energético del edificio, mejorando el confort de los residentes y contribuyendo a la descarbonización del parque inmobiliario.
