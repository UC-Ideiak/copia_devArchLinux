# Impermeabilización de Instalación Deportiva

Proyecto de impermeabilización integral para el campo de fútbol de Las Arenas, garantizando la estanqueidad de las instalaciones deportivas municipales.

## Sistema empleado

Se aplicó un sistema de membrana sintética de alta durabilidad, resistente a la pisada y a las inclemencias meteorológicas, permitiendo el uso intensivo de las instalaciones durante todo el año.
