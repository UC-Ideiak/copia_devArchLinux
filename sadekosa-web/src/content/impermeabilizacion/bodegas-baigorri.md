# Impermeabilización en Bodega de Vino

Proyecto de impermeabilización para Bodegas Baigorri, bodega emblemática de la Rioja Alavesa. Se realizó la instalación de un sistema de protección que garantiza la conservación de las instalaciones vinícolas.

## Solución técnica

Se implementó un sistema de impermeabilización adaptado a las necesidades específicas de una bodega, considerando las particularidades del proceso de elaboración del vino y la necesidad de mantener condiciones óptimas de temperatura y humedad.
