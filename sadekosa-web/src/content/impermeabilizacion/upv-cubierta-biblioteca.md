# Impermeabilización de Biblioteca Universitaria

Proyecto de impermeabilización para la cubierta de la Biblioteca de la Universidad del País Vasco en Leioa.

## Solución implementada

Se instaló un sistema de impermeabilización de alta resistencia mecánica, adecuado para cubiertas transitables y subjectedas a uso universitario intensivo.
